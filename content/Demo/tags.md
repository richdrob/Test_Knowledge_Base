Like many other systems.  Quartz uses tagging as an additional way to organize and group similar knowledge together.  It is one of the core features we will use in our [[knowledge structure]] if we move forward with this site and system.  The reason tags are so versatile, is while a document can only have one location, a it can have an unlimited amount of tags.

---

## how we plan on using tags

Here are a few ways that we plan on using tags.  If we move forward with this system, a more detailed guide will be created.

#### Search Optimization

Being able to find information quickly is critical for IOC staff members.  thanks to tagging, In addition to being able to search for any article on the site, you can also refine your search by first searching for a tag.  We plan on creating tag groups for related concepts to allow for more efficient searching on the site.  

> [!example]-
> We will likely divide our knowledge into separate folders for Voice over IP devices and access layer switches because they both have a different service owner.  However both generate alarms in #spectrum .  If we apply the #spectrum tag to each individual note related to a spectrum alarm, we could search our site using `#spectrum <alarm name>` instead of individually searching through a rigid folder structure.
